# TypeScript Guidelines

1. Use named import for node builtin modules, don't use default import.
2. Use `node:xxx` rather than `xxx` when import node builtin modules.
3. Documentation comment all export APIs.
4. Don't add comments inside function body.
5. Use English for all comments, and add a dot at the end of each sentence.
6. Don't insist on strict English grammars, make it clear and concise.
